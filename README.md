# Randy Jeremi — Portfolio

A clean, technology-driven creative portfolio: editorial layouts, a signature interactive 3D object and a walkable 3D art exhibition. Built with Next.js 16 (App Router), React 19, TypeScript, Tailwind CSS 4, React Three Fiber / Drei, GSAP, Motion and Lenis.

## Run

```bash
npm install
npm run dev      # http://localhost:3000
npm run build && npm run start
```

## Edit your content

| What | Where |
| --- | --- |
| Name, intro copy, disciplines, email, socials, timezone, navigation | `config/site.ts` |
| CV — experience, education, awards, skills, PDF link | `data/cv.ts` |
| All projects (add / remove / edit) | `data/projects.ts` |
| Discipline names, descriptions, services | `data/categories.ts` |
| Project images | `public/images/projects/<project-id>/` |
| Certificate images | `public/images/certificates/` → set `certificate.src` in `data/cv.ts` |
| Downloadable CV PDF | `public/cv/` → set `pdfUrl` in `data/cv.ts` (the button appears automatically) |
| Live demo pages | `public/demos/` |
| Colours, fonts, spacing tokens | `app/globals.css` (`@theme`) |

Every page reads from `data/projects.ts`, so adding a project there makes it appear in the archive, its category page, and (if `featured: true`) the homepage. The exhibition shows the ids listed in `galleryProjects`.

The current project artwork is **placeholder** art generated by `npm run placeholders` (`scripts/generate-placeholders.mjs`). Replace the files with real `.jpg/.png/.webp` images and update the paths.

## Routes

- `/` — hero (interactive 3D gimbal), about + disciplines, selected works, 3D art exhibition, contact
- `/portfolio` — archive overview, three disciplines, filterable archive (`?filter=uiux-design`)
- `/portfolio/graphic-design` — masonry gallery + horizontal detail strip
- `/portfolio/uiux-design` — 3D devices hero, device-mockup case studies
- `/portfolio/web-development` — 3D monitor hero, browser mockups with live previews
- `/portfolio/vibe-coding` — legacy route, redirects to `/portfolio/web-development`
- `/cv` — digital résumé with expandable timeline, certificate previews and print styles

## Notes

- 3D scenes are code-split, only mount near the viewport, pause offscreen and use adaptive DPR. Each has a non-WebGL fallback; the exhibition switches to a swipeable gallery on touch devices.
- `prefers-reduced-motion` disables smooth scroll, the intro loader, the custom cursor and heavy motion.
- `/cv` is print-friendly: "Print / Save as PDF" opens every entry and hides the site chrome.
