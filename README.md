# Creative Portfolio

An immersive, street-art-meets-studio portfolio built with Next.js 16 (App Router), React 19, TypeScript, Tailwind CSS 4, React Three Fiber / Drei, GSAP ScrollTrigger, Motion and Lenis.

## Run

```bash
npm install
npm run dev      # http://localhost:3000
npm run build && npm run start
```

## Edit your content

| What | Where |
| --- | --- |
| Name, wordmark, email, socials, timezone, about text | `config/site.ts` |
| All projects (add / remove / edit) | `data/projects.ts` |
| Discipline names, colours, services | `data/categories.ts` |
| Project images | `public/images/projects/<project-id>/` |
| Live demo pages | `public/demos/` |

Every page reads from `data/projects.ts`, so adding a project there makes it appear in the archive, its category page, and (if `featured: true`) the homepage.

Placeholder artwork is generated by `npm run placeholders` (`scripts/generate-placeholders.mjs`). Replace the files with real `.jpg/.png/.webp` images and update the paths; non-SVG images are optimized automatically by `next/image`.

## Routes

- `/` — hero (3D spray can), about + interactive disciplines, pinned horizontal selected works, 3D gallery room, contact
- `/portfolio` — archive hero + stats, category rooms, filterable list/grid archive (`?filter=uiux-design`)
- `/portfolio/graphic-design` — poster collage hero, editorial wall, services index
- `/portfolio/uiux-design` — 3D device hero, process, scroll-driven device case studies
- `/portfolio/vibe-coding` — 3D live-coding monitor, browser cards with live iframe previews

## Notes

- 3D scenes are code-split, only mount near the viewport, pause offscreen and use adaptive DPR. Each has a non-WebGL fallback.
- `prefers-reduced-motion` disables smooth scroll, the intro loader, the custom cursor and heavy motion.
- The contact form opens the visitor's mail app (no backend needed). Hook it up to a form service if you prefer.
